# The Excuse That Almost Works

A one-line program for [The Excuse That Almost Works](https://make.fun/c/u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5) bounty on make.fun: it writes a single excuse — the kind a gamer texts their boss to skip work on GTA 6 launch week — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

The program writes one line of plain text (at most 20 words, 1–140 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, defaulting to `/output/entry.txt`.
